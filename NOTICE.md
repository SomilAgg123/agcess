# Restoration notice

This is a portfolio restoration of the Agcess team project originally developed in 2022. It is not a snapshot of an operating production service.

Original client configuration, contact information, credentials, encrypted data, decryption keys, and Git histories are excluded. Example organizations, messages, records, and identifiers in this repository are fictional.

The original repositories did not include a project license. This restoration does not assign a new open-source license to shared work; a license remains to be agreed by the relevant contributors. Contributor credits are retained in AUTHORS.md.

The browser demo is a simulation. It does not send SMS, email reports, or connect to a production database. Operational and usage claims should not be inferred from the sample records.
