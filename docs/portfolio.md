## Agcess — agricultural field data, captured through SMS

Agcess turns structured text messages into agricultural records that can be explored through dashboards and reports. The project connects a familiar way to communicate in the field with tools for reviewing operations.

The original system combined Python message parsing, Flask endpoints, Twilio SMS integration, and PostgreSQL storage. Dashboard work spans an earlier Dash implementation and a React interface, with an Airtable-based reporting path also present in the source.

The restored portfolio demo shows the core idea in one flow: enter a fictional field-work message, inspect the structured result, and add it to a dashboard. Visitors can filter records, compare labor hours by activity, and export a CSV. The demo runs in the browser and uses fictional data throughout.

Built as part of a team. Somil Aggarwal's work included much of the SMS functionality and dashboard.
